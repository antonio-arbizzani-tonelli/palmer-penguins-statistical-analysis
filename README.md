# Palmer Penguins: Statistical Modelling in R

This project studies the relationship between penguin morphology and body mass, then uses the same measurements to distinguish Adelie from Chinstrap penguins. The analysis was developed as a group project in statistical inference and later reorganised into a clear R codebase.

The repository covers multiple linear regression, model diagnostics, cross-validation, two-way ANOVA and logistic regression. The emphasis is on interpretation: each model is accompanied by diagnostic checks, numerical summaries and figures that can be used in the presentation.

## Main questions

1. Which measurements and categorical variables are associated with body mass?
2. Does the difference in body mass between species depend on sex?
3. How well do bill and flipper measurements distinguish Adelie from Chinstrap penguins?

## Results in brief

- The full body-mass model explains about 88% of the adjusted variation in the sample.
- Species, sex and their interaction are significant in the two-way ANOVA. The interaction has a p-value of 0.000166.
- The Adelie-Chinstrap classifier reaches an in-sample accuracy of 96.1% and an AUC of 0.993.

The classification metrics are exploratory. The model was evaluated on the same observations used to estimate it, so these values should not be read as external validation results.

## Analysis structure

The scripts are intended to be run in order:

```text
scripts/01_prepare_data.R
scripts/02_exploration_and_linear_model.R
scripts/03_validation_and_anova.R
scripts/04_species_classification.R
```

`scripts/run_all.R` runs the complete analysis from the project root.

```r
source("scripts/run_all.R")
```

The same command can be run from a terminal:

```text
Rscript scripts/run_all.R
```

The code requires R 4.1 or later and the following CRAN packages:

```r
install.packages(c(
  "boot", "car", "corrplot", "dplyr", "GGally",
  "ggplot2", "pROC", "readr", "tidyr"
))
```

The scripts report missing packages without installing them automatically.

## Statistical scope

The data are observational. Regression coefficients and ANOVA effects describe associations within this sample and do not establish causal relationships.

The linear-model section includes residual checks, influence measures, BIC-based selection and cross-validation. The classification section reports the confusion matrix, ROC curve, odds ratios and a goodness-of-fit check. A future extension would use nested resampling or an independent test sample for the final classifier.

## Data source

The data come from the Palmer Penguins dataset distributed with the [`palmerpenguins`](https://allisonhorst.github.io/palmerpenguins/) R package. The repository contains the 324 complete observations used throughout the analysis.

Horst, A. M., Hill, A. P., and Gorman, K. B. (2020). *palmerpenguins: Palmer Archipelago (Antarctica) penguin data*. R package.
